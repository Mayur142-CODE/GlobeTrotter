# GlobeTrotter

Empowering Personalized Travel Planning

## Overview

GlobeTrotter is a full-featured travel planning platform designed to make crafting multi-city adventures simple, inspiring, and organized. It combines an intuitive frontend with a Supabase-powered backend to deliver real-time trip management, budget tracking, and itinerary building.

## Features

- **Personalized Multi-City Itineraries**: Plan complex multi-stop journeys with interactive stop cards and timeline visualizations.
- **Trip Planning**: Effortlessly configure departure dates, destinations, travelers, and transport details.
- **Destination Discovery**: Search and explore global cities with curated details and highlights.
- **Activity Discovery**: Discover points of interest and top attractions per destination.
- **Budget Planning**: Categorize and track travel expenditures with real-time budget summaries.
- **Calendar & Timeline**: Visual day-by-day itinerary schedule.
- **Public Trip Sharing**: Share trip itineraries publicly via secure shareable links.
- **Profile & Settings**: Manage traveler profile, dietary preferences, and travel styles.

## Frontend Development

### Prerequisites

- Node.js (v18+)
- npm

### Setup & Run

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
